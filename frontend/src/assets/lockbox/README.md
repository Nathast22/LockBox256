# Imágenes de Lockbox
Mi mascotica :3

Una animación por estado, en bucle, con fondo transparente, en formato `.gif`.

| Archivo | Cuándo se muestra |
|---|---|
| `greeting.gif` | Al abrir la app y en reposo |
| `thinking.gif` | Esperando la respuesta de la API |
| `encrypted.gif` | Cifrado exitoso |
| `decrypted.gif` | Descifrado + integridad verificada |
| `worried.gif` | Contraseña incorrecta |
| `alarm.gif` | El SHA-256 no coincide |

Los gifs los hice con gemini, elimine el fondo a mano con ezgif.com
